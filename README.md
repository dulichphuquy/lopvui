# Lớp Vui – Trò chơi học tập

Bản web cài được của Lớp Vui: vòng quay gọi tên, chia nhóm, đố vui, lật thẻ và kho câu hỏi soạn sẵn theo SGK Kết nối tri thức.

- Mở: https://dulichphuquy.github.io/lopvui/
- Cài vào máy: bấm nút "⬇ Cài vào máy" trên thanh trên cùng (Chrome, Edge, Cốc Cốc). Sau khi cài, mất mạng vẫn dùng được.
- Có bản mới, app tự báo "Có bản Lớp Vui mới · Cập nhật".

Thư mục `kho/` chứa các gói câu hỏi (mỗi file một môn, một khối). Mã nguồn gốc nằm ở thư mục MaNguon trên Google Drive của tác giả.
